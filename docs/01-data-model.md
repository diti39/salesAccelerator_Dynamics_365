# 01: Data model and declarative configuration

Everything lives in an unmanaged solution named **Sales Accelerator** (publisher prefix `new`). Work in the same environment you test in.

## Columns added

### Lead
| Display name | Logical name | Type | Notes |
|---|---|---|---|
| Company Size Score | `new_companysizescore` | Whole Number (0-3) | Input to scoring |
| Budget Score | `new_budgetscore` | Whole Number (0-3) | Input to scoring |
| Lead Score | `new_leadscore` | Whole Number (0-10) | Written by the plugin |
| Qualified | `new_qualified` | **Yes/No** | Written by the plugin |

### Opportunity
| Display name | Logical name | Type | Notes |
|---|---|---|---|
| Discount Percent | `new_discountpercent` | Decimal (0-100) | Requested discount |
| Deal Probability | `new_dealprobability` | Whole Number (0-100) | Bound to the PCF gauge |
| Source Lead Score | `new_sourceleadscore` | Whole Number | Copied from the Lead on qualification |

> Logical names are always lowercase even if the schema name shows capitals. The plugin code uses logical names. Choosing the wrong data type is easy to do (see PROBLEMS-AND-FIXES #14), so check each one.

## Forms

Adding a column to a table does **not** put it on a form. Add the columns above to the form that is actually active and used by your app:

- Opportunity: **Lead qualification opportunity form** (the *Information* form was switched off in my environment).
- Lead: whichever Main form has status *On* and is first in Form Order.
- Also add *Est. Revenue* (`estimatedvalue`) to the Opportunity form if you want to type values for the flow test.

Test in the **Sales Hub** app, not a default app generated by the trial.

## Business rule (declarative baseline)

**Discount Justification Required** (Opportunity): if `new_discountpercent > 15`, show an error on Description. It was the first implementation of the rule. It is now **deactivated** because the JavaScript (client) and plugin (server) versions replaced it, and running all three made it impossible to tell which one was firing.
